- Keyboard navigation relies on a global window keydown listener (hooks/use-
    keyboard-navigation.ts).
  - In production (build/start) the guard that skips text inputs works, but
    under npm run dev that global handler still fires before the browser inserts
    characters, so the spacebar never reaches controlled inputs like upload
    title/description or the search field.
  - We tried several mitigations (ignoring space in the hook, adding
    stopPropagation on inputs, limiting shortcuts to Enter only) but the dev
    server’s hot-reload environment keeps logging the space key before React
    updates form state.
  - Bottom navigation also listens for space, so accidental presses select tabs,
    further exposing the issue during dev.
